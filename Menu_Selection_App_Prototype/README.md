# Project: Healthy and Tasty Food App
Goal: Create a prototype application to help people eat healthier and tastier food. The project consists of three stages: research (in Jupyter Notebook), development (Python module), and the program (Python script).

Main Tasks:
Main Program (nutritionist.py):

Takes a list of ingredients.

Predicts the dish rating (bad, so-so, great).

Returns nutrient information and their daily values.

Finds the top 3 most similar recipes with ratings and URLs.

Development Module (recipes.py):

Create classes and methods for data processing.

Research (in Jupyter Notebook):

Data preparation (filtering, using the Epicurious dataset).

Rating prediction (regression and classification).

Collecting nutrient information via API.

Finding similar recipes and saving data to CSV.

Bonus Part:
Add a function to generate a daily menu (breakfast, lunch, dinner) considering nutritional needs and ratings.

Outcome:
The project enhances Python and Data Science skills while creating a prototype. The result is an app that helps users choose healthy and tasty recipes.
