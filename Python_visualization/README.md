# Data Visualization with Pandas, SQL, Matplotlib, Seaborn, and Plotly
Goal: Practice data visualization techniques using Python libraries to analyze and present data effectively.

Tasks:
Mandatory Part:

Exercise 00: Create a line chart showing daily page views from a database.

Exercise 01: Plot a line chart comparing page views and commits over time.

Exercise 02: Create a bar chart analyzing user commit times (night, morning, afternoon, evening).

Exercise 03: Compare average commits on working days vs. weekends using bar charts.

Exercise 04: Use histograms to compare commit distributions on working days and weekends.

Exercise 05: Create a boxplot to analyze variances and outliers in user behavior data.

Exercise 06: Use a scatter matrix to explore correlations between page views, commits, and deadlines.

Bonus Part:

Exercise 07: Create heatmaps to analyze commit patterns by weekday and hour.

Exercise 08: Use Seaborn to visualize commit dynamics in a competition project.

Exercise 09: Create an animated line chart using Plotly to show commit trends over time.

Outcome:
Develop skills in data visualization, explore patterns in user behavior, and create interactive and static graphs to communicate insights effectively.
